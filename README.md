# Homebrew Quark Tap

Homebrew tap for [Quark](https://github.com/crazy-vedic/Quark).

## Installation

```bash
brew tap crazy-vedic/quark
brew install quark
```

## Formula

The formula is automatically generated and updated by GoReleaser on each release.

## Development

This repository is maintained by automated processes. For issues with Quark itself, please visit the [main repository](https://github.com/crazy-vedic/Quark).
